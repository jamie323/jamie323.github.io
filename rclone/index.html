rclone

Jamie Thomson's personal Google Drive connection.

This OAuth application lets Jamie use the rclone desktop command-line tool to manage files in Jamie's own Google Drive. It is a personal configuration, not a public sign-in service or the official rclone project.

What the connection does

rclone runs on Jamie's computer. When Jamie runs a command or authorizes a task, it can list, read, upload, download, copy, move, rename, or delete Drive files. The connection requests the full Google Drive permission needed for these file operations, excluding Google's Application Data folder.

File contents and metadata are used for these owner-directed operations between the computer and Google Drive. There is no separate hosted application service for this connection.

Privacy and control

OAuth credentials and tokens are held in rclone's local configuration. Jamie can revoke the connection through Google Account connections. Read the privacy information for storage, deletion, and hosting details.
